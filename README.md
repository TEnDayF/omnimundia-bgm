# Omnimundia · 随境配乐

为 Omnimundia 文字冒险自动搭配本地背景音乐的浏览器扩展。AI 判断当前剧情情绪，插件在本地曲库里选择音乐。

适用于 Chrome Manifest V3；Edge 可使用同一份扩展，但尚未完成安装与播放实测。本项目为独立辅助工具，不是 Omnimundia 官方扩展。

## 下载与安装

在 [Releases](https://github.com/TEnDayF/omnimundia-bgm/releases) 下载 `Omnimundia-BGM-Chrome-v1.4.3.zip`，解压后得到 `extension` 文件夹。

1. 打开 Chrome 扩展管理页，开启开发者模式。
2. 选择“加载已解压的扩展程序”，选中含 `manifest.json` 的 `extension` 文件夹。
3. 打开扩展的“曲库与设置”，完成下方配置。
4. 刷新 Omnimundia 游戏页。

更新时在原加载目录替换插件文件，再点击“重新加载”。已有曲库时不要先卸载扩展；不同加载目录可能产生不同扩展身份。

## 首次使用

1. **AI 配置 → 管理服务**：填写服务地址、接口类型和鉴权信息，并授权该来源。
2. **添加模型**：获取服务的模型列表或填写实际模型 ID。显示名称与模型家族可以自行修改。
3. **功能分配**：为情境判断选择一个模型；单曲说明转标签可沿用该模型或另行指定。
4. **音乐管理**：导入本地音频，为音乐设置适用情绪、标签、排除情境和强度，并保存。
5. 返回前台游玩页面，点击 **开始配乐**。

首次安装不附带任何服务密钥、个人曲库或游戏数据。保存配置不会自动调用模型；“测试一次分类”“说明转标签”和“重新判断”会分别产生显式请求。

## 功能

- 工作台展示当前播放、选曲依据、游戏连接状态及运行检查。
- 一个回合自动调用一个指定后端，失败不自动切换收费服务或重试。
- 复用相同剧情判断缓存；普通换曲、音量调整和曲库编辑不调用模型。
- 本地选曲、多情绪分类、标签排除、单曲音量、交叉淡入淡出。
- 离开前台游玩页面停止背景播放；手动暂停保持有效。
- 悬浮播放器可拖动并记忆位置，提供暂停、下一首及锁定控制。
- 曲库备份与恢复、曲目回收、回合缓存清理与恢复。

## 模型接入

支持 OpenAI Chat Completions 兼容接口，以及 TypeSafe System One/Jev 适配接口。DeepSeek 与提供兼容接口的本地模型服务走统一配置流程。模型家族仅用于命名提示，不代表验证了服务商身份或模型能力。

暂未适配 OpenAI Responses、Gemini 原生和 Anthropic Messages 协议。真实服务需要自行填写配置并验证；自动测试使用模拟响应，不代表所有模型均已实测。

## 隐私与权限

音频保存在浏览器扩展的本地数据库中。模型情境判断会将当前剧情及必要上下文发送给你选择的服务；使用远程模型时，这部分文本会离开本机。

服务密钥保存在 `chrome.storage.local` 中，插件没有额外加密。仓库和发行包不包含个人配置、密钥、音频、剧情数据或浏览器资料。详情见 [隐私与数据流](docs/PRIVACY.md)。

## 从源码构建

使用 Node.js 22 或更新版本：

```sh
npm ci
npm run check
npm run build
npm test
```

构建产物在 `extension/`；测试辅助构建在 `tests/built/`。仓库包含可直接加载的插件构建产物。当前 52 项自动测试通过，覆盖请求去重、错误处理、缓存、数据恢复、界面流程及音频控制。

目录：`src/` 为 TypeScript 源码，`extension/` 为浏览器插件，`tests/` 为自动测试。实现结构见 [架构说明](docs/ARCHITECTURE.md)。

## 已知限制

- 网站结构变化可能影响剧情识别。
- 实际音频格式支持取决于浏览器。
- 工具栏弹窗 v1.4.1 已完成本地界面和初始尺寸检查，安装后的实际显示需在使用环境确认。
- 使用前请自行准备有权使用的音乐及模型服务。
