# 隐私与数据流

## 本地保存

- `chrome.storage.local`：服务地址与密钥、模型、用途、播放偏好和用量。插件没有额外加密这些配置。
- IndexedDB：导入的音频副本、音乐分类与说明、判断结果、缓存和可恢复操作记录。
- 运行过程中，扩展后台持有当前游戏正文及状态，用于检测回合和控制播放。

清理回合缓存不会自动清空曲库、服务配置或用量。可恢复备份保留期间仍占用本地空间。曲库导出不包含模型连接密钥；按选项可包含音频，分类和说明也会导出，请自行决定备份文件的分享范围。

## 网络请求

情境判断发送当前回合剧情、必要的游戏状态、上一回合的情绪判断信息，以及配置的情绪类别和标签。只发送当前分类所需输入，不逐回合累积完整聊天上下文，也不上传音频文件。

主动执行“说明转标签”会发送该首音乐的文字说明；获取模型列表请求服务目录；模型测试发送短样例。请求目的地为用户指定的服务。远程地址要求 HTTPS，本机回环地址可以使用 HTTP；鉴权信息用于选定的服务，不跟随自动重定向。

项目没有独立的遥测、广告或开发者收集服务器。所选第三方模型服务如何保存和使用接收到的内容，由该服务的政策决定。

## 权限

- `storage`：保存扩展配置与状态。
- `unlimitedStorage`：保存用户导入的音频。
- `offscreen`：后台音频播放。
- `https://omnimundia.cn/*`：在目标网站识别游玩页。内容脚本限定该域名，回合识别还要求游戏路径与页面元素匹配。
- 可选 HTTPS 及本机地址权限：配置模型时按具体服务来源申请，不等于默认读取所有网站。

## 发布范围

发行仓库只包含程序源码、构建产物、测试和公开说明。测试中的 `fake-test-key`、`private-key` 等字符串为模拟值，不是可用凭据。未包含开发机截图、路径记录、个人配置、浏览器数据库、真实游戏数据、音频或访问令牌。
